# MediTrack — Medicine Inventory & Patient Issue Dashboard

A responsive, static demo for tracking medicine stock, patient medicine issues, expiry dates, low-stock alerts, and CSV issue-history export.

## Run locally
Open `index.html` in a modern browser, or serve the directory with any static web server.

## Deploy
This is a static HTML app and can be deployed on Vercel without a build command. Connect this repository to Vercel or deploy the files directly.

## Important limitations
- Demo data is stored in the browser's localStorage on the current device/browser. It is not a shared database.
- Do not enter real patient names or sensitive health information in this demo.
- It is not a clinical prescribing tool. Production use requires a secured backend/database, authentication and role-based access, transaction-safe stock changes, audit logs, backups, and appropriate privacy/security review.
